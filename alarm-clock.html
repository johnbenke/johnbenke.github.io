Microcontroller-Based Alarm Clock

Introduction to Circuits · Final project · March – May 2025

A working alarm clock built end to end on an Arduino Uno platform: multiple independent alarms, a user control interface and multiple audio outputs. I owned the entire build — sourcing, circuit design, embedded programming and physical assembly — which meant every integration problem between the hardware and the firmware was mine to find and mine to fix.

Full ownership

  • Designed, wired, programmed and assembled a functional alarm clock on an Arduino Uno microcontroller platform.
  • Integrated multiple independent alarm functions, a user control interface and multiple audio output speakers.
  • Owned component sourcing, circuit design, embedded software programming, and physical assembly and integration.
  • Arduino Uno
  • Embedded programming
  • Circuit design
  • Hardware/software integration
