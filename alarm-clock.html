Microcontroller-Based Alarm Clock

Introduction to Circuits · Final project · March – May 2025

A working alarm clock built end to end on an Arduino Uno, from parts sourced online — a digital time display, three independently settable alarms, each with its own soundtrack, and a set of buttons that make it usable without a manual. The point of the exercise was to show how a company could put a working prototype together cheaply.

What it does

  • Digital display for the time, driven off the Arduino Uno board.
  • Three independent alarms, each of which can be set separately.
  • Three different soundtracks, one per alarm. There is no audio file here — each tune had to be written as a song in the Arduino code, note by note, and played out through the speakers.
  • Multiple speakers, plus a button interface designed so the clock is easy to operate.
  • All of the wiring is packaged inside the box: off the Arduino board, out to the speakers, the display and the buttons.

My part

  • I built the clock physically — component sourcing, circuit layout, wiring and getting it all to fit and function inside the enclosure.
  • I wrote a good portion of the code, including the songs and the button programming.

What I took from it

Composing an alarm tone in code is a strange way to discover that firmware and hardware are the same problem — the speaker only sounds right if the timing in software and the wiring on the board agree. Packaging it all inside the box afterwards was its own constraint: everything has to fit, stay connected, and still be reachable by someone pressing a button.
